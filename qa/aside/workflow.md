# 생성·제출·내보내기 분기 케이스

명시적 --allow-writes 실행에 한함. 이번 실행의 QA 접두사-single(1건)와 -weekly(최대2건), 해당 보고서만 생성/편집한다. 그 외 반복/시간 테스트는 미리보기에서 멈추고 등록하지 않는다. 실행 순서는 3 → 4-b → 5 → 4-c → 8. 생성 실패한 전제를 필요로 하는 케이스는 BLOCKED로 처리하고 독립 케이스는 계속한다. 이번 실행에서 추가한 사진만 삭제할 수 있다. 기존 데이터·권한·양식·메일·수업 취소는 금지한다. 개인 사진 탐색 금지. 비개인 합성 사진은 `artifacts/aside/fixtures/qa-photo.jpg`와 `qa-photo.png`만 사용한다. 없거나 파일 업로드 도구가 지원하지 않으면 사진 분기는 BLOCKED. 실행 끝에 생성 데이터 URL/ID 목록을 보고한다.

Aside 파일 선택기는 세션 밖 경로를 거부할 수 있다. 그 경우 `node scripts/prepare-aside-image-fixtures.mjs --aside-session <이번 Aside 세션 ID>`로 같은 합성 이미지를 해당 세션의 `tmp`에 생성해 그 경로만 업로드한다. 수업 등록은 STEP 4의 날짜 미리보기와 별도 `수업 등록` 버튼을 먼저 확인한다. STEP 3 `다음` 이후 뜻밖에 상세 화면으로 이동하거나 데이터가 생기면 추가 반복·시간 경계 시도를 중단하고 생성 ID를 기록한다.

숫자=기능, 소문자=상황, 대문자=말단 검증. 추가 숫자는 더 세밀한 하위 분기다. 부모 단위로 일괄 PASS하지 않고 표의 각 ID마다 결과를 남긴다. 필수 전제가 없으면 이유와 상위 실패 ID를 적는다.
