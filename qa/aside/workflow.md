# 테스트 데이터 생성·제출·내보내기

명시적으로 쓰기를 허용한 실행에만 사용한다. 아래 작업은 허용된 테스트 계정과 이번 실행의 QA 접두사 데이터에만 수행한다. 기존 데이터 수정/삭제와 테스트 데이터 자동 정리는 금지한다.

| ID  | 실행                                                                  | 기대 결과                                                                                                               |
| --- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| W01 | 실행 접두사로 단일 수업 생성. 시간 미지정, 진행방식·메모 입력         | 새로고침 후 입력값 보존. 시간 미정 표시                                                                                 |
| W02 | 실행 접두사로 반복 수업 생성. 오늘부터 7일 뒤까지 매주 요일 하나 선택 | 최대 2개만 생성. 선택 요일과 종료일 준수                                                                                |
| W03 | W01 수업에서 보고서 작성. 인원 항목이 있다면 휠로 0 선택 후 3 선택    | 숫자 선택과 저장 동작 정상. 해당 항목 없으면 BLOCKED                                                                    |
| W04 | 일부만 입력하고 임시저장. 목록에서 다시 열기                          | 내용 보존, 기본 읽기 전용. 수정 버튼으로만 편집                                                                         |
| W05 | W01 보고서에서 필수 항목을 비우고 제출 시도                           | 제출 거절과 오류 안내. 입력값 유지                                                                                      |
| W06 | W01 보고서의 필수 항목 입력, 합성 테스트 사진 제공된 경우 한 장 첨부  | 썸네일과 사진 삭제 버튼 정상. 개인 파일을 탐색하거나 임의 사용하지 않음. 사진 미제공 시 사진 검사는 BLOCKED             |
| W07 | W01 보고서 제출 후 목록과 상세 조회                                   | 제출 성공 후 목록 이동, 새로고침 후 내용 보존, 상세 읽기 전용, 승인 단계 없음                                           |
| W08 | W01 수업을 이름 검색으로 선택하여 보고서 조회                         | 결과가 W01 수업으로 제한되고 날짜 아래 선택 수업명 표시                                                                 |
| W09 | 관리자 계정에서 W01 수업만 선택해 PDF와 Excel 내보내기                | 두 다운로드 성공, 한글·작성자·답변 확인. 파일을 열 수 없으면 내용 검사는 BLOCKED. PDF 사진은 파일명·첨부 ID가 현재 명세 |

작업 중 계정 변경·구성원 초대·양식 생성/게시·권한 변경·수업 취소·파일 삭제는 하지 않는다. 유효한 보고 양식이 없으면 보고서 테스트를 BLOCKED로 기록한다. 내보내기의 수업 선택으로 W01을 특정하지 못하면 내보내지 않는다.

마지막에 생성한 수업/보고서의 이름, URL, 가능하면 ID와 내보내기 파일 경로를 목록으로 남긴다. 같은 실행 접두사가 이미 존재하면 중복 생성하지 말고 중단한다.
