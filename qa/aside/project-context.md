# Flag Edu — 최신 확정 기준

이 문서는 과거 구현 문서보다 우선하는 QA 기대 동작이다. 테스트 대상 화면을 보고 기준을 임의로 변경하지 않는다. 기준 변경은 사용자 결정 → Codex 문서/코드 변경으로만 반영한다.

## 목적과 원칙

교육 기관의 관리자가 코치를 초대하고, 수업별로 코치가 보고서를 남기는 모바일 우선 웹앱/PWA다. Next.js·Vercel·Supabase 기반이다. 기관별 데이터 격리와 작성자 권한을 유지한다. 실사용자 데이터가 없는 개발 환경에서 테스트한다.

- UI는 stoic. 참고의 밝은 회색·흰색·검정 중심, 넉넉한 여백, 제한적인 노랑 강조. 장식/설명보다 간결한 입력과 조회를 우선한다.
- 기능을 먼저 완성하고 사용 흐름을 검증한다. 새 기능·디자인 제안은 개선점이지 확정 명세가 아니다.
- 주요 작업은 별도 브랜치에서 commit/push. main 병합 및 운영 영향 작업은 사용자 승인 후 수행한다.

## 요구사항 ID와 기대 동작

- R01 공통 UI: 홈(`/dashboard`) 좌측 상단 로고, 다른 화면은 같은 위치에 뒤로가기만 표시. 수업·보고서 결과는 PC/모바일 모두 1열. 날짜/필터는 작은 버튼. 페이지 대기는 화면에 문구 없이 회전 그래픽으로 표시하며 접근성 이름은 허용한다. 모션 감소 설정 준수.
- R02 로그인/권한: 관리자 초대 방식, 초대 수락 시 사용할 비밀번호 설정. 대기 구성원 표시 및 메일 재발송. 관리자와 코치의 기능을 구분하고 다른 기관의 데이터는 접근 불가. 메일 발송은 기본 QA 범위 밖이다.
- R03 수업: 정보→반복→날짜/시간→확인 순서. 일/주/월 간격과 종료일 포함. 주는 요일 여러 개, 월은 날짜 선택(없는 날짜는 말일). 시간은 선택. 시간 미정에 가짜 자정 표시 금지. 진행방식과 메모 저장. 반복 생성 최대 366건, 수정/취소는 한 건씩. 임의 일괄 수정 기능은 요구하지 않는다.
- R04 보고서: 기본 읽기 전용, 작성자만 수정 버튼으로 편집. 상태는 임시저장/제출 두 개. 불완전한 임시저장 허용, 제출 시 필수값 검증, 성공 후 목록 이동. 제출된 내용을 임시저장하면 draft로 전환. 관리자 확인/승인 기능은 삭제된 요구사항이다.
- R05 입력/사진: 인원·개수 등 수량은 휠 선택, 일반 소수 입력은 기존 숫자 필드. 인원 0 보존. 도움말은 가능한 입력의 placeholder로 표현. 사진은 썸네일·추가/촬영·편집 시 삭제. 사진 변경은 별도 저장되고 보고서는 임시저장 상태가 된다. 실제 모바일 카메라는 실기기 검증이 필요하다.
- R06 보고서 조회: 보고서 제목으로 수업명을 표시할 수 있으며 작성 메타정보는 이름과 작성일시만 표시한다(접두어·양식 v1·상태 뱃지 없음). 상태 필터 없음. 수업명 검색 결과 중 수업 선택 후 조회, 적용 수업명을 날짜 아래 표시. 수업 검색은 최대 30건. 보고서 날짜 필터는 수업 시작일 기준이다.
- R07 양식: 관리자만 작성·게시. 사용자에게 양식 이름을 우선 표시(예: 기본 양식), 내부 버전은 과거 보고서 구조 보존용이다. 템플릿 관리 화면의 내부 버전까지 제거할 필요는 없다.
- R08 내보내기: 관리자 PDF/Excel 생성·다운로드. 범위 1~200보고서. 한글·답변·0 값 보존, Excel 답변 문자열을 수식으로 실행하지 않음. 사진은 파일명/첨부 ID만 포함하며 원본 이미지 삽입은 미구현이 아닌 현재 제한이다. 생성 이력/파일 저장은 쓰기 작업이다.
- R09 안전성: 코치의 관리자 기능, 다른 기관/다른 작성자 수정, 중복 등록, 동시 수정 덮어쓰기를 차단. 취소 수업의 기존 기록 보존, 새 보고서 생성·제출 차단. 권한 테스트를 위해 실사용자의 계정을 변경하지 않는다.

## 테스트 시 해석

미구현 제안(PDF 사진 원본 삽입, 반복 수업 일괄 수정 등)을 FAIL로 보고하지 않는다. 관찰로 입증된 기준 위반만 BUG 후보로 기록한다. 선호도/새 기능은 IMPROVEMENT로 분리한다. 로그인·사진·실기기·계정 등 전제가 없으면 BLOCKED이며 PASS가 아니다. 권한 테스트는 승인된 전용 계정/데이터 없이는 수행하지 않는다.
