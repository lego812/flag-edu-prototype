# 별도 승인·환경 분기 케이스

설계된 미실행 케이스. 현재 CLI 시나리오로 선택할 수 없다. 메일·계정·권한·취소·장애주입·실기기는 사용자 승인과 별도 준비 후에만 실행한다. 모든 항목의 현재 상태는 NOT_RUN이며 코드 테스트로 대체 통과시키지 않는다.

숫자=기능, 소문자=상황, 대문자=말단 검증. 추가 숫자는 더 세밀한 하위 분기다. 부모 단위로 일괄 PASS하지 않고 표의 각 ID마다 결과를 남긴다. 필수 전제가 없으면 이유와 상위 실패 ID를 적는다.
