# 조회 전용 점검

데이터 생성·수정·삭제·제출·내보내기 작업을 하지 않는다. 내보내기는 서버에 이력이 생성되므로 조회 전용 점검에서는 실행하지 않는다.

| ID  | 실행                                                 | 기대 결과                                                                                     |
| --- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| S01 | 홈으로 이동                                          | 좌측 상단에 로고만 있고 뒤로가기 버튼이 없음                                                  |
| S02 | 수업 목록으로 이동                                   | 좌측 상단에 뒤로가기만 있고 로고가 없음. 뒤로가기 작동                                        |
| S03 | 수업 목록과 상세 조회                                | 카드가 한 열. 진행방식·메모와 날짜가 정상 표시. 시간 미지정 수업에 가짜 시간이 없음           |
| S04 | 보고서 목록과 기존 보고서 조회                       | 최초 진입은 읽기 전용이며 입력칸과 사진 삭제 버튼이 없음                                      |
| S05 | 본인 보고서에서 수정 클릭, 입력 없이 조회로 돌아가기 | 수정 화면에서만 입력칸과 임시저장·제출 버튼이 나타남. 조회 화면에서는 사라짐                  |
| S06 | 보고서 메타데이터와 필터 확인                        | 이름·일시만 표시. 작성자/작성일시 접두어, 양식 버전, 승인 버튼 및 상태 필터 없음              |
| S07 | 수업명 검색 결과 하나를 선택하고 조회                | 선택한 수업의 보고서만 표시되며 필터 날짜 아래에 수업명 표시. 검색 결과가 없으면 빈 결과 안내 |
| S08 | 조회 필터 접기·펼치기                                | 버튼으로 작동하며 결과 카드 한 열 유지                                                        |
| S09 | 페이지 이동 시 로딩 상태 확인                        | 대기가 발생하면 문구 대신 회전 그래픽. 너무 빨라 확인 못 했으면 확인 불가                     |
| S10 | 좁은 화면에서 위 페이지 확인                         | 브라우저가 뷰포트 조절을 지원하는 경우에만 모바일 크기로 확인. 버튼·필터가 잘리지 않음        |

보고서/수업 등 전제 데이터가 없으면 생성하지 말고 해당 항목을 BLOCKED로 기록한다. 다른 사람의 보고서는 수정하지 않는다. 일반 브라우저의 좁은 화면 검사를 실제 모바일 기기 검사로 보고하지 않는다.
