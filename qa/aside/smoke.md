# 조회 전용 분기 케이스

조회 전용. 생성·저장·제출·내보내기·삭제 금지. 로그인된 테스트 계정만 사용한다. 없는 전제조건은 BLOCKED. 기존 보고서는 입력 없이 읽기/편집 진입만 확인한다.

개발 환경 재검증 fixture: 2026-09-23 `테스트 수업` 회차에 QA 코치의 임시저장 보고서가 있다. 관리자 `전체 보고서`에서 이 회차를 선택하면 1건, 동명 2026-09-24 회차를 선택하면 0건이다. `내 보고서`는 관리자 본인 작성분만 보여 주므로 타 작성자 케이스에는 사용하지 않는다. 이 fixture가 실제 화면에서 확인되지 않으면 BLOCKED로 남긴다.

Aside의 창 크기 설정 API가 없으면 동일 출처의 임시 iframe을 390px/1280px로 열어 내부 뷰포트와 카드 위치·문서 너비를 측정하고 끝나면 제거한다. 브라우저 클릭 명령이 CDP 시간 초과라면 새 스냅샷을 얻고 동일 버튼을 Enter 키로 재시도한다. 도구 오류 자체를 제품 FAIL로 기록하지 않는다.

숫자=기능, 소문자=상황, 대문자=말단 검증. 추가 숫자는 더 세밀한 하위 분기다. 부모 단위로 일괄 PASS하지 않고 표의 각 ID마다 결과를 남긴다. 필수 전제가 없으면 이유와 상위 실패 ID를 적는다.
