# 보고서·수업 UX 개선 (2026-09-23)

- 보고서는 기본 조회 전용. 작성자만 `수정`으로 편집하며 신규 작성은 편집 화면으로 진입한다.
- 상태는 임시저장 / 제출. 상태 필터와 관리자 확인 UI·서버 액션·DB 승인 RPC를 제거한다.
- 과거 확인 정보 컬럼은 기존 기록 보존을 위해 남기되 사용하지 않는다.
- 제출 후 수정한 내용을 임시저장하면 다시 draft가 된다. 제출은 필수 항목 검증을 수행한다.
- 수업명 검색은 로그인 사용자의 기관 범위에서 실행하고 결과 중 하나를 선택한다. 최대 30건을 표시하므로 검색어를 구체화할 수 있다.
- 수업 진행방식(선택, 2,000자)과 메모(선택, 5,000자)를 등록·수정 및 상세에서 사용한다.
- 인원/개수 등 수량 항목은 휠 선택(0~1,000), 반복 간격은 1~365, 최대 사진 수는 1~10. 일반 소수 숫자 입력은 기존 입력 유지. 기존 저장값은 자동 절삭하지 않는다.
- 공통 로딩 경계는 문구 없는 회전 그래픽이며 모션 감소 설정을 따른다.

## 배포

`202609230001_simplify_reports.sql`은 승인 RPC 삭제와 수업 진행방식 컬럼 추가 및 저장 RPC 변경을 포함한다. 2026-09-23 사용자 승인 후 `flag-edu-dev` 원격 DB에 적용했고 로컬·원격 마이그레이션 일치를 확인했다.

## 검증 범위

자동 테스트: PostgreSQL 마이그레이션·권한·제출/임시저장·동시 수정, 조회/편집 권한, 검색 선택, 수량 선택, PDF 한국어 장문 페이지 분할, Excel 수식 문자열 안전성, 내보내기 API의 권한·범위·파일 반환·업로드 실패 정리.
