# UI 기준

색상 참고: https://mobbin.com/colors/brand/bereal

- 흰색 `#FFFFFF` 배경, 검정 `#000000` 글씨와 주요 버튼
- 노랑 `#FFCC4D`는 예정·초대 대기와 같은 강조 상태에 제한적으로 사용
- 노랑 위 글씨는 검정. 보조 정보와 테두리는 무채색 회색
- 오류·위험 행동의 빨강은 의미 구분을 위해 유지하고 항상 설명 문구를 함께 표시
- 그림자와 중첩 카드를 줄이고 여백·구분선으로 영역 구분
- 버튼·입력창 모서리는 8px, 키보드 포커스는 검정 윤곽선
- 좁은 화면에서 메뉴·구성원 상태와 버튼은 줄바꿈 허용
- 업무 기능과 권한 로직은 UI 변경과 분리

공통 색상은 `src/app/globals.css`, 설치용 색상은 `src/app/manifest.ts`에서 관리한다.
수업 관리 기능을 포함한 `feat/class-management` 기반의 UI 브랜치에서 적용했다.
실제 브라우저·모바일 화면 검증은 연결 가능한 브라우저에서 별도 확인해야 한다.
